🔒 Privacidad

ID Camper no solicita ni almacena cuentas, contraseñas ni datos personales. La extracción de un ID a partir de una URL se realiza localmente en el dispositivo. Las búsquedas de lugares utilizan servicios externos para geocodificación y consulta de áreas. Las solicitudes pueden quedar registradas por esos proveedores conforme a sus propias políticas de privacidad. ID Camper no se presenta como una aplicación oficial ni está afiliada a Park4Night.
